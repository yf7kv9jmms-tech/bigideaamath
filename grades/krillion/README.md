# Krillion Offline Solo Edition

This local single-player edition runs without a server, network requests, third-party scripts, or remote assets. Open `index.html` directly or launch it from the grade library.

The supplied website capture is a rendered production page, not a source project. Its gameplay calls server routes such as `/api/krillion/answers` and `/api/krillion/deal`, which were not included in the capture. This edition therefore implements a self-contained solo prompt deck and is not an exact offline port of the online service.

The original Krillion game and concept belong to Playdaily. This independent offline implementation uses no captured production JavaScript, stylesheets, or images.
